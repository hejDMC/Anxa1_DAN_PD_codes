# Fiber Photometry and Optogenetic Stimulation

This directory contains R scripts for analyzing fiber photometry responses to optogenetic stimulation during open-field recordings and generating representative traces and summary figures.

## Scripts

| File | Description |
| --- | --- |
| `01_Optogenetic_Stimulation_PETH.R` | Detects stimulation onsets from Bonsai recordings, groups events into bursts, extracts peri-event fluorescence signals, and exports PETH tables and individual-recording figures. |
| `02_Optogenetic_Stimulation_Graphs.R` | Generates the original representative dStr and vStr traces, summarizes PETHs across recordings, and assembles the combined figure. |

## Inputs

The scripts expect the experimental metadata file `oft_fp_opto_details.csv` and recording-specific files in a directory structure such as:

```text
<data directory>/
  oft_fp_opto_details.csv
  <experiment>/
    videos/<video>.csv
    signal/<video>_signal_df.csv
  results/
    <video>/<video>_PETH.csv
```

The second script reads PETH CSVs generated by the first. It also uses the original `.mat` file ordering to select the representative recordings (indices 1 and 17); this ordering should be checked when reproducing the figure on a different computer.

## Running the analysis

1. Set `DATA_DIR` in each script to the local experimental data directory.
2. Run `01_Optogenetic_Stimulation_PETH.R` to generate recording-level PETH files.
3. Run `02_Optogenetic_Stimulation_Graphs.R` to produce the representative traces and combined figure.

## Analysis notes

- Behavioral and photometry sampling intervals are specified as 1/30 s and 1/60 s, respectively.
- Photometry traces are filtered with a third-order Butterworth filter (`butter(3, 0.1)`).
- PETH fluorescence is normalized by the maximum of the filtered recording signal. The representative raw traces are filtered but not normalized.
- The representative dStr and vStr traces retain their original example indices and plotting windows.

## Outputs

- `results/<video>/<video>_PETH.csv`: event-aligned fluorescence and experimental metadata.
- `results/<video>/<video>_PETH.pdf`: recording-level PETH figure.
- `results/Extended_Data_Figure_4IJ.pdf`: combined representative traces and summary PETH figure.

## Software

R with `ggplot2`, `dplyr`, `signal`, and `cowplot` (the second script). Package versions are not pinned. Raw experimental recordings are not included in this directory.
